# Shahriar Islam — Portfolio

A Next.js + TypeScript portfolio starter using real assets extracted from the supplied project archives and research papers.

## Run locally

1. Install Node.js 20.9+.
2. Open this folder in VS Code or a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Before publishing

- Verify every project contribution and project link.
- Replace the FYDP abstract placeholder with a verified figure from the final-year project report.
- Replace the temporary Smart Assistance System visual with a figure extracted from its own paper.
- Add dedicated BazarDor, FitLog and Dev Stack screenshots if available. Current images for these are original project assets/banners, not UI screenshots.
- Add the correct individual repository URLs for projects where only the profile URL is currently linked.
- Add a CV PDF when ready.

## Structure

- `src/app/page.tsx` — portfolio content and sections
- `src/app/globals.css` — responsive dark theme styling
- `public/images/` — project visuals extracted from supplied source files

All project role labels reflect the contribution levels provided by Shahriar. Do not change them to individual ownership unless confirmed.
